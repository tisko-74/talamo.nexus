SQL

Consultas em um banco de dados que roda dentro do seu navegador. Nada é instalado e nada é enviado para servidor nenhum.

O QUE É ISTO

SQL é a linguagem para perguntar coisas a um banco de dados. O banco aqui é o SQLite, o mais usado do mundo (está no seu celular), carregado na página pela biblioteca sql.js.

A base de exercícios tem duas tabelas públicas do IBGE: os 27 estados e os 5.571 municípios do Brasil. Elas se ligam pela coluna codigo_uf.

Uma consulta sempre segue esta ordem (só SELECT e FROM são obrigatórios):

  1. SELECT quais colunas
  2. FROM de qual tabela (JOIN … ON para ligar outra)
  3. WHERE filtro das linhas
  4. GROUP BY agrupar · HAVING filtrar os grupos
  5. ORDER BY ordenar · LIMIT quantas linhas

SEUS DADOS

Abra um arquivo CSV do seu computador e consulte com SQL. O arquivo é lido só pelo navegador: não sai da sua máquina e some ao fechar a aba.

A página descobre o separador (vírgula, ponto e vírgula ou tabulação), transforma os títulos em nomes simples (sem acento, espaço vira _) e reconhece números. Com ponto e vírgula, aceita vírgula decimal (12,5); números com separador de milhar (1.234,56) ficam como texto.

Sugestão: baixe um CSV público (Câmara dos Deputados, IBGE, portal da transparência) e cruze com a tabela municipios pelo código do IBGE.
