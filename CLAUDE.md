## Como responder
- Português padrão; evitar estrangeirismos (manter só termos sem tradução).
- Prefixo de domínio nas respostas: **[WEB]** para este repositório.
- Indicar confiança: **[Certeza]** / **[Provável]** / **[Suposição]**.
- Verdade difícil primeiro; sem elogios nem frases vazias; discordar com "Discordo porque X e o risco é Y".

## Como trabalhar
- Uma pasta por projeto; caminhos relativos; sem dependências externas sem necessidade.
- Alterações cirúrgicas: não reformatar nem "melhorar" código vizinho.
- Mudanças por branch + pull request; a `main` vai ao ar.
- Ambiente do usuário: computador sem permissão de instalação (ALESC). Tudo deve funcionar online.
- O repositório é público: nunca gravar chaves, senhas ou dados pessoais.
